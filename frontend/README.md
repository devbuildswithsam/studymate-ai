# StudyMate AI — frontend

React + TypeScript (Vite), Tailwind CSS, shadcn/ui, React Router and TanStack Query.
Setup and how to run the whole project: see the [root README](../README.md).

```bat
npm install
npm run dev          :: http://localhost:5173 (needs the API on 127.0.0.1:8000 for /api)
npm test             :: Vitest + Testing Library
npm run lint         :: ESLint
npm run format       :: Prettier
```
