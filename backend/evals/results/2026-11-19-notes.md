# First evaluation runs: notes (19 Nov 2026, SMA-51)

Two runs on the same 30 cases, each with fallback off (only that model answers):
`2026-11-19-openai-gpt-oss-120b.md` (Groq, the default chat model) and
`2026-11-19-gemini-3.5-flash.md` (Gemini, the fallback). Run with `--pause 30`.

## What the numbers say

**GPT-OSS 120B is a good default (confirms ADR-0007).** All 5 of its misses are *false
refusals* ("not found"), never a wrong answer: zero invented citations, every "not in the
documents" question refused. The cautious failure mode is the right one for a study tool.

- 3 of the 5 misses are **retrieval** misses (hit@5 = no: fr-08, th-03, ph-06): the right
  page never reached the model. The same 4 cases miss for both models, as expected, since
  retrieval doesn't depend on the chat model. This is the first thing to improve.
- 2 misses had the right chunk in the top 5 (th-01, ph-05) but the model still said "not
  found": possibly the strict grounding rule, or the chunk only partly covers the answer.
- 3 citations were scored incorrect on correct answers (ph-01, ph-04). ph-01's fact also
  appears on page 1 ("chlorophylls ... reflecting green"), which the case doesn't list; the
  CSV doesn't record the cited pages, so this needs a re-check (see follow-ups).

**Gemini 3.5 Flash was not usable on the free tier during this run** (as in ADR-0007):
12 timeouts (61 s each), 7 "unavailable" (503), then 9 quick failures. A check right after
the run got HTTP 429: the quota was used up, and the fallback manager skips a model while it
cools down after a 429. This run labels those 9 as "error"; the harness now labels them
`rate_limited` and records the reason (`error_detail`) for future runs. The 2 cases that did
answer were correct and correctly cited.

**Open question:** case fr-05 in the Gemini run took 5,881 s (98 minutes). Each API read has
a 60 s timeout, but the client sets no limit on a call's total time; the computer sleeping
during the run would also explain it. Not reproduced.

## Suggested follow-ups (new tickets, not done here)

1. **Retrieval:** look at fr-08, th-03, ph-06 (e.g. smaller chunks, or searching with the
   rewritten question plus key terms) and re-run to see hit@5 move.
2. **Harness detail:** record the cited and retrieved pages per case in the CSV, so citation
   scores can be checked by hand; correct ph-01's expected pages if page 1 is confirmed.
3. **A total time limit per AI call** (e.g. 90 s), so one stuck call can't stall a request.
4. Re-run Gemini on a day with free quota, or drop it as the fallback if it stays unusable.
